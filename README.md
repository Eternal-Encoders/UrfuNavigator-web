Repo branched from the deprecated https://github.com/Roaoch/UrfuNavigator

The floor canvas is [`@eternal-encoders/konva-floor-plan`](docs/floor-plan.md).
Set `NODE_AUTH_TOKEN` to a GitHub token that can read packages, then install:

```powershell
$env:NODE_AUTH_TOKEN = "<GitHub token with read:packages>"
pnpm install
```
